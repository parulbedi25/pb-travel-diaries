# PB media folder

Drop photos here (JPG, PNG, WEBP) and they are served as:

```
/media/your-file-name.jpg
```

You can paste that path into any image field in the admin dashboard.

**Easier option:** open `#/admin` → **Media** and upload from your computer. Those files are stored in this browser’s media library and can be picked on any section without an internet URL.
